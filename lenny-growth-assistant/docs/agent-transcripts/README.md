# Agent transcripts

This folder is reserved for the coding-agent transcripts/logs required by the assessment.

When using Claude Code, Codex, Cursor, Pi, or another coding agent to develop the project, export sanitized transcripts here.

For each meaningful failed attempt, record:

- date/time
- goal
- agent instruction
- relevant output/error
- diagnosis
- correction
- verification

Never commit API keys, cookies, access tokens, private customer data, or other secrets.
